# AFKCore

**AFKCore** is an open-source Windows utility for Roblox designed to prevent AFK inactivity through configurable automated actions.

The project focuses on **flexibility, reliability, low resource usage, and convenient background operation**.

---

## 📖 About

AFKCore is designed to automatically perform a configured action in Roblox at specified intervals.

One of the main features of the project is its ability to work alongside other applications.

For example, if the user is working in another application while Roblox is running in the background, AFKCore can temporarily switch to Roblox, perform the configured action, and then return to the previously active application.

The goal is to make this behavior configurable while keeping the application simple and predictable for the user.

---

## ✨ Planned Features

* ⏱️ Configurable action intervals
