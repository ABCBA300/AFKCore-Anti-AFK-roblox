## AFKCore
AFKCore — это утилита для Windows с открытым исходным кодом для Roblox, разработанная для предотвращения AFK-кика за неактивность с помощью настраиваемых автоматических действий. Проект ориентирован на гибкость, надежность, низкое потребление ресурсов и удобную работу в фоновом режиме.

🇬🇧 English version

------------------------------
## 📖 О проекте
AFKCore предназначен для автоматического выполнения настроенного действия в Roblox через заданные интервалы времени. Одна из главных особенностей проекта — способность работать параллельно с другими приложениями. Например, если пользователь работает в другой программе, пока Roblox запущен в фоновом режиме, AFKCore может временно переключиться на Roblox, выполнить настроенное действие, а затем вернуться к ранее активному приложению. Цель состоит в том, чтобы сделать такое поведение настраиваемым, сохраняя при этом приложение простым и предсказуемым для пользователя.
